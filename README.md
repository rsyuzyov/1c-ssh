# 1C:Enterprise SSH Agent Integration

Скрипты для загрузки конфигурации и запуска отладки через SSH-агент конфигуратора 1С.

## Назначение

Скрипты запускают конфигуратор 1С в режиме агента SSH. Это позволяет:

1. Загружать конфигурацию и расширения из XML файлов.
2. Обновлять конфигурацию базы данных.
3. Запускать режим предприятия с отладкой.
   Все операции выполняются без закрытия основного окна конфигуратора.

## Структура проекта

- `1c_config.json`: Основной файл конфигурации. Содержит пути к платформе, параметры подключения к базе, учетные данные агента.
- `start_agent.bat`: Скрипт для удобного запуска `start_agent.ps1`.
- `start_agent.ps1`: Скрипт для запуска агента конфигуратора на Windows.
- `start_agent.sh`: Скрипт для запуска агента конфигуратора на Linux (требует `jq`).
- `agent_runner.py`: Модуль, реализующий логику взаимодействия с агентом через SSH (загрузка, обновление, запуск).
- `mcp_server.py`: MCP сервер
- `requirements.txt`: Список зависимостей Python.

## Настройка и запуск

1.  Установите Python зависимости:

    ```bash
    pip install -r requirements.txt
    ```

2.  Отредактируйте `1c_config.json`:
    - `platform`: укажите версию и пути к платформе 1С.
    - `infobase`: укажите строку подключения, пользователя и пароль базы.
    - `agent`: настройте порт и учетные данные для SSH доступа к агенту.
    - `project`: укажите имя расширения и путь к XML файлам.

3.  Запустите агент конфигуратора:
    - **Windows**: запустите `start_agent.bat` (или `start_agent.ps1`).
    - **Linux**: запустите `./start_agent.sh`.

    Откроется окно конфигуратора. Не закрывайте его.

4.  Настройте MCP сервер в вашем агенте, указав команду запуска:
    ```json
    {
      "mcpServers": {
        "1c-debug": {
          "command": "python",
          "args": ["/path/to/project/mcp_server.py"]
        }
      }
    }
    ```

## Использование

В чате агента используйте команду (например):
"Загрузи расширение и запусти отладку"

Ассистент выполнит через MCP сервер загрузку XML, обновление конфигурации БД и запустит предприятие в режиме отладки.
